# 网页模拟器 · 规则与产品原型

已有 GitHub 仓库提供了家族经营类网页原型，展示复杂规则如何转成可操作的浏览器产品。本项归为原型开发，不宣称游戏内接入了大模型。

## 百年门第

[仓库](https://github.com/uo13/bainian-mendi-simulator) · [已有试玩入口](https://uo13.github.io/bainian-mendi-simulator/)

中国古代世家经营模拟器。现有 README 包含婚姻家谱、科举官途、庄园产业、商队贸易、宗族建设、动态事件和浏览器存档等系统。制度为游戏抽象，不作为历史还原。

## 决策卡

| 决策卡 | 内容 |
| --- | --- |
| 用户问题 | 复杂家族经营规则难以被读懂；规则迭代后交互与存档容易失效 |
| 目标指标（假设） | 新玩家完成开局引导的比例 / 关键规则能被找到并读懂 / 存档跨版本不丢失 |
| 关键取舍 | 规则抽象为游戏机制、不宣示历史还原；原型优先浏览器可玩，不引入后端与账号体系 |
| 复核结果 | 三个仓库入口可访问；未重新验收全部游戏功能 |

以上为设计意图与假设，不是已验证的业务数据。
