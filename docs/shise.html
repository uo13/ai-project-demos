PROJECT NOTES / 2026.10.17

拾色 · 参考图仿色

照片参考图表达的是视觉方向。项目将模型输出约束为可编辑的调色参数，再由本地像素引擎应用到原图。

产品与实现

  • 输入原图、参考图及风格意图，计算色彩统计，向模型请求结构化方案。
  • 校验请求与图片标识、JSON 字段、曲线单调性和参数范围；错误结果不覆盖上一份成功方案。
  • 本地应用曝光、对比、曲线、色温、分离色调、八组 HSL；独立调整影调和色彩强度。
  • 提供原图对照、取消、导出和错误反馈；密钥只保存在页面内存中。
原图 + 参考图 → 统计与意图 → AI 参数方案 → 契约校验
                                         ↓
                       本地像素渲染 → 强度调节 → 导出

本仓库演示

  • demos/shise/index.html 保留已有 2.0 单文件网页，使用者自行输入 DeepSeek 密钥。
  • 作品集的免密钥调色板直接复用上述网页的 neutral、recipeAtStrength、renderPixels 生产函数。预设由本次演示人工定义，不是 AI 实时分析的输出。
  • 默认场景为程序绘制的示意图，支持上传自己的照片；离线调色板不发送图片到服务器。
  • 本地还有 3.0 双引擎实验版本，涉及生成式改光、参数反演及可选分割模型。本仓库选用独立易运行的 2.0 展示版本，不发布未复核许可的模型文件。

验证边界

随仓库保留的引擎测试覆盖：中性与 0% 保真、透明度、HSL 局部色相、200% 曲线单调、独立强度、重复字段与图片 ID 校验。实际执行结果见 验证记录。

本次未发送付费 AI 请求，未验证当前 API 的模型可用性、照片理解能力或真实仿色质量。历史 README 中的接口描述不能代替当下实测。生产使用前需在所选提供方确认支持图像输入的模型与接口契约。
