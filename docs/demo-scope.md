# 演示范围与数据处理

| 入口 | 实际做什么 | 是否调用 AI | 输入处理 |
| --- | --- | --- | --- |
| 作品集调色板 | 既有拾色渲染代码 + 人工预设 | 否 | 本地 Canvas，上传图片不发出 |
| 完整拾色网页 | 原图与参考图分析、参数方案、本地渲染 | 点击运行且提供密钥时会尝试调用 | 两张缩小的分析图发送给 DeepSeek |
| 格式检查器 | 检查部分可确定的文本格式 | 否 | 浏览器内处理 |
| 结构因子检索 | 六条新写样例的关键词筛选 | 否 | 浏览器内处理 |
| 外部模拟器 | 跳转已有项目 | 以原项目为准 | 以原项目说明为准 |

无需账号即可操作本作品集。代码不使用分析埋点、广告或浏览器持久化。下载由浏览器生成，输入数据不会因下载发送到服务器。静态托管服务可能产生其常规访问日志。

完整拾色 Demo 会在用户主动运行时连接第三方 API，需要用户自己的有效密钥和余额。请在该工具页面查看其说明；本次没有验证提供方当前的接口能力。

默认图像为代码绘制，检索记录和剧本片段为本次演示新写；均不作为真实客户数据、拍照实测或历史创作成果。
