PROJECT NOTES / 2026.10.17

AIPhoto · iOS 智能相机

将参考图追色接入相机产品：模型负责色彩方向，端侧引擎负责参数渲染、预览与输出。

工作内容

  • 使用 SwiftUI、AVFoundation、Core Image 与 Metal 连接相机、预览和成片流程。
  • 处理参考图颜色统计、色彩迁移、滤镜预览与导出链路。
  • 梳理并修复后置画面方向、旧帧覆盖、拍摄状态竞态与请求取消等问题。
  • 为像素方向、裁切、广播生命周期与 AI 请求边界补充回归入口和验证说明。
相机输入 → 方向归一化 → 滤镜 / 追色参数 → 实时预览
                                      ↘ 拍照处理 → 相册
参考图 → 色彩分析 → 参数校验 ────────────┘

能展示什么

这一案例侧重模型分析与可控图像处理的分工，以及相机生命周期问题的工程化处理。跨平台的调色交互可在本作品集的拾色 Demo 中体验；它不是 iOS 相机的运行画面。

已知限制

本次在 Windows 整理源码与历史修复报告，没有执行 Xcode 编译、Mac 像素测试或 iPhone 真机验收。历史修复说明也明确区分语法检查与编译通过。

Live Photo、RAW 与普通 JPEG 的滤镜输出路径不同；不能把 JPEG 预览行为推广为所有格式均通过。设备分辨率、HDR、旋转和实际保存行为仍需真机复核。

项目基于 Apple AVCam 示例并包含第三方图像库；本仓库只发布整理后的案例说明，不转存整套工程或移除原署名。
