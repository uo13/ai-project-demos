# 短剧生成与质检工作流

将长任务拆成明确交付物，减少多集写作中的格式漂移、人物状态遗失和修改不可追踪。

## 已有工作流

```text
项目配置 → 参考材料 → 人物与信息状态 → 分集节拍
    → 分场剧本 → 格式检查 → 编辑审稿 → 定点修订
    → 连续性复核 → 交付与状态归档
```

主要资产包括项目配置、人物与关系台账、分集节拍、正式剧本、质量问题记录和修订说明。国内与海外项目分别处理语言、场景和文化语境，不直接套用统一集数。

## 关键设计

- 区分观众已知、角色已知、作者设定，避免秘密提前泄漏。
- 把动作、对白、场景和集尾承接写成可定位的交付约束。
- 将格式校验与编辑判断分开；修订定位到具体场次，保留问题及处理理由。
- 多轮任务落盘状态，继续时复用配置与连续性台账。

## 可交互演示

作品集中的格式检查器是本次补做的轻量演示：编辑样例后检查集标题、场次编号、内外景与时间、人物表、动作标记、角色对白。支持下载检查结果。

它不调用模型、不生成正式剧本、不判断角色是否可信，也不提供文学质量百分制或 AI 检测比例。输入样例为本次新写，仅用于说明格式约束。

完整的人工审稿仍需检查冲突递进、人物动机、反转兑现、可拍性与连续性。未在本次发布中上传第三方 IP 的完整改编稿或未经授权的案例正文。
