花令 Agent · 档案驱动的持续对话

面向东方命理与主题对话场景的产品。围绕用户建立的档案，支持持续追问与不同主题的内容入口。命理内容属于文化娱乐场景。

项目工作

既有项目材料记录了产品与全栈开发工作，包括需求和流程设计、前后端接口、Agent 与对话链路、功能排查与交付。

本地代码包含 React / TypeScript 前端、FastAPI / Python 后端、SQLite、身份认证、档案与多模型服务，以及玩法广场的统一解析与不同渲染器入口。

用户输入 → 身份与档案 → 主题 / 玩法入口 → Agent / 模型服务
                                                ↓
                                  输出处理 → 对话展示 → 后续追问

产品判断

  • 档案建立和连续追问需要相互衔接，避免每次对话重新填写背景。
  • 不同玩法共享入口解析，减少重复查找与前后端定义不一致。
  • 模型提供内容能力；应用承担数据、状态、输入输出契约及错误处理。
