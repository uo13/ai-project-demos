## 3 分钟看完

1. 打开作品集，在「拾色」区域切换色彩方案、拖动强度，或上传一张自己的图片。该预览使用拾色已有像素渲染函数，不调用 AI。
2. 在「内容工作流」中运行格式检查，修改场景行或删除动作标记，观察检查结果。
3. 在「结构因子」中搜索「公开 核验」或「职业 重建」，查看检索到的示例记录及因果链。
4. 打开六篇项目说明，查看问题、方法、可核查交付和限制。

页面里的剧本片段和六条检索记录是本次新写的演示数据，不冒充历史交付，不包含第三方正文。

## 本地运行

需要 Node.js 20 或更新版本，无需安装依赖。

```bash
npm run dev
```

打开终端显示的 `http://127.0.0.1:4178`。也可直接双击 `index.html`。

```bash
npm test          # 拾色已有生产引擎测试 + 作品集交付检查
npm run build    # 生成 Pages 静态产物 _site/
```

仓库 Settings → Pages → Deploy from a branch，选择 `main` 与 `/(root)`。本项目无需在线构建；根目录 `.nojekyll` 保留静态文件行为。本地 `npm run build` 也可以产出仅包含站点文件的 `_site/`。
